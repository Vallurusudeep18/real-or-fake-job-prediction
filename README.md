# 🛡️ fake job posting dedection

## AI-Based Fake Job Posting Detection and Verification System

JobShield AI is an AI-based application designed to help job seekers identify potentially fraudulent job postings.

🚀 Features

- Real/Fake job prediction
- Machine Learning-based detection
- Confidence score
- Fraud risk score
- Suspicious phrase detection
- Risk level classification
- Job information extraction
- Safety recommendations
- PDF report generation

🧠 Machine Learning

The system uses:

- TF-IDF for text feature extraction
- Logistic Regression for classification
- Kaggle Fake Job Postings dataset

🛠️ Technologies Used

- Python
- Scikit-learn
- Streamlit
- Pandas
- NumPy
- Joblib
- Regular Expressions
- FPDF2

⚙️ How It Works

Job Description
→ TF-IDF
→ Logistic Regression
→ Real/Fake Prediction
→ Fraud Risk Analysis
→ Verification
→ Safety Tips
→ PDF Report

🎯 Objective

To help job seekers identify potentially fake job advertisements and make safer decisions before applying.
